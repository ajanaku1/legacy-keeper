# LegacyKeeper identity

The selected mark is **Sentinel C — Split Shield**. Two asymmetric dark-green
defensive panels protect a bright signal-green core. The split seam represents
the monitored KeeperHub execution path: guarded by default, actionable only
through verified automation.

## Final assets

- `finals/legacykeeper-mark.svg` — primary colour mark
- `finals/legacykeeper-mark.png` — 512px raster export
- `finals/legacykeeper-mark-mono.svg` — single-colour mark using `currentColor`
- `finals/favicon.svg` — scalable browser icon
- `finals/favicon.ico` — 16/32/48px browser icon set

Dashboard copies live in `dashboard/public/`. Exploration candidates remain in
their render folders and are not production assets.

## Palette

- Signal green: `#09FD67`
- Active green: `#06B171`
- Structural green: `#043D2B`
- Deep background: `#031B13` at 68% opacity
- Near-black green: `#020A07`

The first ideation pass used the built-in image-generation route. Its shading
and symbol drift were rejected; the selected production mark was redrawn as
deterministic flat SVG geometry with exact colour values.
