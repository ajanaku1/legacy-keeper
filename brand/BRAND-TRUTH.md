# LegacyKeeper — Brand Truth

- **name:** LegacyKeeper
- **purpose:** Preserve a verifiable path for assets and instructions when their owner can no longer act.
- **core_verb:** Monitor, verify, execute.
- **metaphor:** An active sentinel gate holds a live signal inside a fail-closed perimeter and exposes only one verified execution path.
- **palette:** KeeperHub signal green `#09FD67` as the sole accent; active green `#06B171`, deep keeper green `#043D2B`, dark green `#031B13`, and near-black `#020A07` as supporting low-saturation greens and neutrals.
- **constraints:** Web logomark and favicon; immediately reads as an active security tool at 16px and rewards inspection at 512px; compact vector silhouette; no text inside the mark; no plain shield, padlock, keyhole, vault wheel, bank imagery, family tree, hourglass, rainbow, robot, sparkle, or multicolour treatment.
