# LegacyKeeper style configuration

- **Brand words:** fail-closed, monitored, credible, tactical, verifiable
- **Color mode:** dark-only
- **Primary accent:** KeeperHub signal green `#09FD67`, reserved for identity,
  healthy states, and the single primary action
- **Surface palette:** midnight navy `#0B1220`, navigation navy `#0E1728`,
  slate panels `#131E31`, blue-grey borders `#2B3A52`
- **Semantic support:** cool blue for progress, amber for incomplete evidence,
  and restrained red for destructive recovery actions
- **Typography:** technical but human; expressive display face plus restrained data mono
- **Motion:** sparse and functional; 120–200ms ease-out; no bounce or ambient loops
- **Signature element:** selected split-shield mark and the narrow verified execution seam
- **Anti-patterns:** green-washed page backgrounds, warm paper theme, brass/gold,
  generic card grids, crypto hexagons, purple gradients, glassmorphism,
  ornamental security clichés
