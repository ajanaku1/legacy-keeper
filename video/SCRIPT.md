# LegacyKeeper demo script

## Hook

A dead man's switch is useless if the transaction never lands. LegacyKeeper treats acceptance as the start, not the result.

## Problem

Most agents stop at an API response. LegacyKeeper requires settlement, a successful receipt, the expected event, and confirmed product state.

## Positioning

The owner signs one short-lived message. KeeperHub sponsors the transaction on Sepolia. LegacyKeeper then verifies the chain independently before showing success.

## Product reveal

This is the live dashboard. It reads the deployed estate, the exact beneficiary split, and every retained execution attempt from real evidence.

## Sponsored check-in

A normal check-in never calls the contract directly. The browser sends only nonce, deadline, and signature to the workflow-specific KeeperHub webhook.

## Recovery and paid proof

Failed attempts stay visible beside the recovered transaction. A separate x402 call also checked the live token allowance and changed the coverage verdict.

## Close

Five enabled workflows. Four automatic trigger types. One hundred and two passing tests. LegacyKeeper proves the last mile before it claims success.
